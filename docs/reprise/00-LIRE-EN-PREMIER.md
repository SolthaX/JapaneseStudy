# Fiches de reprise — Benkyō 勉強

Ces fiches permettent de reprendre le projet dans une nouvelle conversation avec Claude, sans rien perdre.
Dernière mise à jour : 18 octobre 2026.

## Comment reprendre

1. Ouvre une nouvelle session Claude Code sur le dépôt `SolthaX/JapaneseStudy`.
2. Copie-colle le contenu de [`prompt-de-reprise.md`](prompt-de-reprise.md) comme premier message.
3. Claude lira ces fiches puis te demandera où tu veux reprendre.

## Où en est-on, en une phrase

L'application web fonctionne et est en ligne. On est en **phase de planification** d'une refonte visuelle (thèmes, tableau de bord personnalisable, compagnons animés en pixel art) et d'une éventuelle app native. **Rien de cette refonte n'est encore codé** : l'utilisateur doit d'abord donner son retour détaillé sur les visuels.
